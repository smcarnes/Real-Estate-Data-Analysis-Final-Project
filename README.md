This project took real estate data from Zillow and created a comprehensve analysis. 
Throughout the code there are text boxes displaying the various questions each section is aiming to answer.
Various display boxes, numerical outputs, and visualizations are used to provide clear explanations to the questions
being asked in each section. This project was designed and developed by myself along with a small team of classmates
as a final project in out Data Analysis and Visualization class at the University of St. Thomas
